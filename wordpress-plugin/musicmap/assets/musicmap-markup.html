Convert this YouTube soundtrack into a MusicMap pack. Videos / Playlists: [PASTE ONE OR MORE URLS] Timestamps: [PASTE CHAPTER LIST — one per video if multiple] MusicMap plays music that matches where the listener is. Sort the tracks into these places by mood: beach (sunny, breezy) · city (busy, night lights) · forest (calm, natural) · mountain (epic, climbing) · desert (dry, hypnotic) · town (friendly, everyday) · ocean (vast, flowing) · shopping (upbeat, playful) · port (industrial, gritty) · home (cozy) · work (focused) · school (light, youthful) · gym (high energy) Return ONLY valid JSON, no explanation: { "name": "Pack Name", "subtitle": "Artist / Game", "icon": "emoji", "videos": [ { "videoId": "abc123def45", "tracks": [ {"title": "Track Name", "start": 0, "dur": 120} ] } ], "biomes": { "beach": [0,3], "city": [1,4], "forest": [2,5], "mountain": [6], "desert": [8], "town": [9,10], "ocean": [11], "shopping": [12], "port": [13], "home": [7], "work": [14], "school": [15], "gym": [16] } } Rules: - videoId = the 11-character id from the YouTube URL - Each playlist video = one track (title = video title, start=0, dur=300) - "start" = seconds from video start - "dur" = seconds to next track (max 300) - biome arrays = track indices across ALL videos combined (0-based, flat) - Prefer one place per track; give every place at least one track - icon = single emoji for the game/music theme

ADD PACK
HOW TO ADD A PACK
1
Find a full OST playlist on YouTube — any game, album or mix works.
2
Paste the YouTube URL below. The video is added instantly and a timestamp field appears.
3
On the YouTube video page, open the description and copy the full timestamp list (chapters). Paste it into the field that appears.
4
Give your pack a name, pick an icon, and hit Save. Then assign tracks to each biome from the 🌴 Biomes tab.
